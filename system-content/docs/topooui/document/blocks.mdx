---
title: "Blocks"
description: "Reusable documentation blocks used by the publishing system."
---
The documentation system reuses a small set of UI blocks:

- board overview matrix cards
- topic navigation groups
- callouts
- package tabs
- preview and code blocks
- reference lists and component indexes

These blocks are reusable presentation patterns inside the approved docs shell. They must not redefine the overall board or sidebar structure.
