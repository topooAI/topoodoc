---
title: "Renderer Contract"
description: "How the documentation renderer maps schema to the live UI."
---
The documentation renderer must preserve:

- top navigation as `board`
- left sidebar gray headings as `block`
- left sidebar dark entries as `topic`
- current board-home matrix pattern
- current page shell, spacing, typography, and docs primitives

## live rule

The current live output is the only accepted rendering baseline.

If local, GitHub, and live diverge, the source must be corrected until they resolve to the same structure and visual result.
