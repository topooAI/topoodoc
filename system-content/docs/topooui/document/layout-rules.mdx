## Layout owns

- shell grid
- column widths
- sidebar placement
- TOC placement
- card grid spacing
- preview/code placement

## Layout does not own

- topic naming
- content semantics
- typography values
- schema hierarchy

Those are handled by content model, renderer contract, and typography.
