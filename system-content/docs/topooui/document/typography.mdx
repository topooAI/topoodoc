Typography in Topoo docs is a fixed reading system extracted from the current live implementation.

## Base font stack

- Sans stack: `Geist Variable`, `Geist`, `ui-sans-serif`, `system-ui`, `sans-serif`
- Mono stack: `ui-monospace`, `SFMono-Regular`, `Menlo`, `Monaco`, `Consolas`, `Liberation Mono`, `Courier New`, `monospace`

## Typography owns

- heading scale
- paragraph size and line-height
- list spacing
- inline code density
- prose rhythm
- readable emphasis

## Typography does not own

- board/block/topic/page structure
- page routing
- sidebar taxonomy
- preview component behavior
- overview grid composition

Those belong to schema, renderer contract, and layout rules.
