This block defines the UI rules for the Topoo documentation system itself.

It covers:

- how the doc system is structured
- which structural layers exist
- how pages are rendered
- how web and desktop publication frameworks are defined
- which reusable documentation blocks are available
- which typography rules control reading rhythm
- which layout rules control page composition
- where content definition ends and renderer responsibility begins

Use these pages as the contract for any future doc-system work under **TopooUI**.

The publication framework is part of this contract.
Topoo Book and Topoo Chatbox can validate the framework in real products, but the shared shell and reusable page patterns belong here.
