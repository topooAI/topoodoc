The canonical model for `doc.topoo.ai` is:

`board -> block -> topic -> page`

## UI mapping

- `board`: top navigation entries
- `block`: gray labels in the left sidebar
- `topic`: dark clickable items under each block
- `page`: the concrete main-content document body

## rule

The current live structure is the product standard.

Engineering changes must preserve the approved live information architecture unless explicitly changed.
