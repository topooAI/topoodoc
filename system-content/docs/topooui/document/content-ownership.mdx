---
title: "Content Ownership"
description: "Boundary between document content and renderer-owned structure."
---
Content authors can define:

- document titles
- descriptions
- body content
- topic/page ordering
- board-specific knowledge content

Renderer-owned layers control:

- page shell
- sidebar structure rendering
- typography baseline
- docs primitive styling
- board-home overview presentation

When a change affects layout, spacing, sidebar behavior, or docs primitives, it is a renderer/system change rather than a content-only change.
